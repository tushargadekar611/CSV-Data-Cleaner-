# CSV-Data-Cleaner-
# 🧹 CSV Data Cleaner MVP | Python & Streamlit

## 📌 Project Overview
CSV Data Cleaner is a web-based application developed using Python, Pandas, and Streamlit to simplify common data preprocessing tasks. It enables users to upload CSV files, inspect data quality, apply cleaning operations, and download cleaned datasets through an interactive interface.

## 🎯 Project Objectives
- Simplify CSV data cleaning and preprocessing.
- Identify missing values and duplicate records.
- Provide an interactive interface for dataset inspection.
- Export cleaned data for further analysis.

## 🚀 Key Features

- **CSV File Upload:** Upload datasets in CSV format for processing.
- **Data Preview:** Inspect uploaded datasets through an interactive table.
- **Missing Value Detection:** Identify columns containing missing values.
- **Data Cleaning:** Handle missing values and remove duplicate records.
- **Interactive Interface:** Perform data cleaning operations through a user-friendly Streamlit application.
- **Download Cleaned Data:** Export the processed dataset as a downloadable CSV file.

## 🛠️ Tech Stack

- **Python:** Core programming language.
- **Pandas:** Data manipulation and cleaning.
- **Streamlit:** Interactive web application development.

## ⚙️ How to Run Locally

1. Clone or download this repository.
2. Install the required dependencies:

```bash
pip install streamlit pandas
```

3. Run the application:

```bash
streamlit run app.py
```

4. Open the local URL displayed in your terminal and upload a CSV file to begin cleaning.
